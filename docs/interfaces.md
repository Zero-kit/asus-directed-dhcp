# 接口识别与选择

软件中心包支持识别和选择已有网络桥、上游回程及下游 Wi-Fi。打开插件页面或点击“重新识别接口”会重新采集；每五秒运行状态刷新不重复枚举无线信息。保存及启动、停止期间暂停自动刷新，页面请求按顺序执行。

网络桥来自 Linux sysfs bridge 标记，桥成员来自 brif。无线接口来自 wl0..wl7 的 NVRAM ifname/vifs 映射，包括独立虚拟接口名称；频段来自 nband，SSID 来自对应无线配置，上游优先使用回程 SSID 配置。SSID 等字符串按 JSON 数据传递，用 textContent 显示，不作为命令或 HTML 执行。

无线模式 ap 标为下游 Wi-Fi，sta/wet/psta/psr 标为上游 Wi-Fi。模式缺失时尝试 wl status 的 AP/Managed/STA/WET 信息；已确认的中继主频段可按 wlc_mode/wlc_band 辅助识别。其他情况显示“角色未确定”，不得默认为 AP。未识别为无线且 type=Ethernet 的接口作为有线回程候选，用户须按实际接线确认。只有属于所选桥的接口才列为可用成员。

选择一个桥、一个回程和一至八个下游 Wi-Fi。桥不能作为自己的成员，回程不能同时作为下游，下游必须识别为 AP。保存保留显式选择；推荐文字不自动覆盖已有配置。接口名称不存在或角色未确认时仍可读取状态与诊断，但保存和启动需重新核对。

启动时检查桥标记、成员关系、接口角色、接口状态、回程 BSSID、唯一默认路由、桥地址和 DHCP 地址池，以及系统 DHCP 排除配置。要求 ip_forward=0，适用于同网段桥接的 AP/中继环境；路由/NAT 模式不在本包范围。系统 dnsmasq 需明确 no-dhcp-interface=所选桥（或 *），指定包含目录仍须为空。

过滤跳转按所选桥生成，下游规则只按所选接口生成。记录桥、回程和下游快照供监控、停止及回滚读取。旧版本没有桥/回程快照时，用其原 br0/eth7 规则约定恢复。不会新建桥、无线虚拟接口或修改 NVRAM；需要新增 SSID 时先在固件无线设置中配置，再重新识别。

安装器检查软件中心目录及工具依赖，不再要求指定型号、内核或软件中心版本号。离线包仍使用 hnd 标识、KoolShare API 1.5 的读写契约和 Broadcom wl 工具；这不是 OpenWrt 或任意品牌固件安装包。不同型号是否支持 ebtables 的实际无线报文路径仍需实机验证。缺少依赖、角色信息、系统 DHCP 排除或实际过滤能力时，不能靠更改型号名绕过。

升级先停止现有服务，将启用及开机设置置为关闭；保留已有配置及接口选择。安装过程中使用临时恢复目录，成功后清理；安装失败且恢复不完整时保留该目录供恢复。安装后核查识别结果、地址池及 DNS，再点击启动；需要开机运行则勾选保存。
