# axdhcp 软件中心长期运行包

当前包为 `dist/axdhcp-0.5.6-interfaces.tar.gz`。包内含 hnd 标识、ASUS 菜单页面、API、接口识别、资源、后端、开机钩子、安装和卸载入口，以及运行和恢复说明。软件中心安装已在先前版本通过；当前接口选择和开机触发需在设备上确认。安装器检查目录及工具依赖，具体适用范围见 `interfaces.md`。

安装及升级不会启动 DHCP。升级先停止旧插件服务和等待中的开机任务；保留配置内容但将后端启用标记及“开机自动运行”置为关闭。旧文件临时移入安装事务目录，用于失败恢复；成功后清理该目录。停止或临时移动失败时拒绝覆盖。历史版本生成的备份不在自动清理范围。

在页面核查地址池、DNS、网关和下游频段，勾选两项地址确认后点击“启动”。确认弹窗后，页面先保存当前配置并启用服务，再请求后端长期运行。正常状态显示“DHCP 运行中”。页面以服务状态、配置和运行记录为主，诊断及使用说明在底部折叠展开。没有客户端时租约表可以为空。

勾选“开机自动运行”并保存后，`/koolshare/init.d/V99axdhcp.sh` 由软件中心 services-start 无参数调用后端 `boot`，适用于 AP/中继模式的服务启动事件。后端串行检查已保存的启用和地址确认，等待网络接口、默认路由及系统 DNS 配置就绪后启动长期运行。最多尝试 90 次，间隔两秒，检查时间另计；超时保持 DHCP 停止并记录原因。入口调用、禁用跳过及已有事务跳过均记录到日志。不会在故障后无限重启。

升级时将旧 S99 入口纳入安装事务，成功后清理，失败时恢复。只读诊断列出开机设置、V99/S99 入口、services-start 文件及 jffs2_scripts 值；安装不改系统 services-start 或 NVRAM 设置。

“停止并恢复”只停止当前运行并取消等待中的开机启动，不改下次重启的设置。若希望重启后仍保持停止，取消“开机自动运行”并保存。保存配置也会取消尚在等待的开机启动，但不会立即启动服务。

启动错误会保留在状态和日志，页面翻译常见错误并展示原始信息。例如 `Configuration is disabled` 表示已保存配置没有启用，不表示 DHCP 已启动后停止。页面普通启动会自动保存启用状态；直接调用后端仍需先保存 enabled=1。

页面通过保存或启动自动维护 enabled=1，无须单独勾选启用。保存只写配置，不启动服务；重启是否启动由“开机自动运行”决定。停止不更改已保存的开机设置。

“停止并恢复”会先停止插件 DHCP，再撤销插件拥有的过滤规则。网络接口、规则或进程异常也会触发停服和恢复；身份不确定或清理失败会保留恢复所需文件和规则并报告故障，不会清空全局防火墙或终止系统 dnsmasq。

普通页面提供持续运行和停止恢复，并通过租约、日志及只读诊断排查问题。后端审查用限时命令仍为 30–300 秒操作，切换模式前先停止。普通启动需明确接受实际客户端及上下游影响尚待验收的风险。

页面 API 仅提供读取、保存、诊断、启动和停止。请求串行执行，保存、启动和停止期间暂停自动刷新并防止重复操作。接口枚举和运行监控复用已查出的无线映射，减少重复读取 NVRAM。

客户端分配、广播/单播隔离、续租和漫游后续验收。运行页按服务实际状态显示运行、停止或故障；租约记录用于核对实际地址分配。发现上游收到插件地址或下游无法领地址，立即停止并保存诊断报告。

租约时间兼容固件的两种记录格式：0 为无限期，1–86400 按本插件允许的租约时长显示，2000 年起的时间戳显示到期日期，中间值提示系统时间异常。只提供时长的记录不能推算准确剩余时间，不随页面刷新重新计算到期日期。

卸载先 stop，再将后端与配置移至可恢复的 `axdhcp.retired.*`，移除插件页面、API、资源和模块元数据。stop 失败时保留安装。运行日志位于 `/tmp/axdhcp-runtime`，重启可能清空，故障时先复制报告。
